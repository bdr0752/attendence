# 大学生考勤系统

按题目保留学生与考勤的新增、查找、修改、删除、列表显示、排序、五类统计报表和文件读写。提供控制台菜单及 MFC 图形界面，使用结构体数组、函数、指针和本地文本文件。

## 运行与编译

- 控制台版：双击 `run.bat`；修改后用 `powershell -ExecutionPolicy Bypass -File .\build.ps1` 编译，需要 GCC。
- MFC版：双击 `run_mfc.bat`；用 VS2026 打开 `mfc/Attendance.sln`，选择 `Release`、`x64`，生成并运行。也可执行 `powershell -ExecutionPolicy Bypass -File .\build_mfc.ps1`，需要 MSVC、MFC与Windows SDK。

## 题目功能

| 要求 | 实现 |
| --- | --- |
| 新增且避免重复 | 学号唯一；同一学生、月日和时间段不可重复登记 |
| 查找、部分或全部显示 | 考勤按学号、姓名、月日精确查询；查询值留空显示全部 |
| 修改、删除 | 修改学生和考勤；修改学号同步关联记录；删除学生同时删除关联考勤 |
| 排序 | 按学号、姓名、月日升序排序考勤 |
| 统计报表 | 明细、日报、汇总、异常、请假五种文本报表 |
| 文件保存与读取 | 数据变更后自动保存，启动时读取；查看报表后自动保存报表文本 |
| 六种考勤符号 | 出勤√、旷课X、事假△、病假○、迟到+、早退– |
| 不少于十条考勤时间段 | 支持时间段编号1～99，测试覆盖十个不同编号 |

## 操作与数据规则

控制台菜单1～4为学生管理，5～7为考勤管理，8为查询，9为排序，10为报表，0退出。MFC通过功能下拉菜单选择学生、考勤及报表；学生和考勤视图可新增、修改、删除，考勤可查询、排序。

姓名和班级保存在学生名单中，每条考勤引用学号并记录月、日、时间段和状态。同一学生允许多次考勤。学号允许1～31个字母、数字、下划线、连字符，保留前导零；这是实现采用的格式规则，题目没有提供学校的具体学号规则。姓名使用下述通用文本校验，不额外限制文字种类或连接符格式。

姓名和班级最多95个UTF-8字节，不能为空或含控制字符、竖线、首尾空白。最多500名学生、20000条考勤。日期按题目仅存月日，允许2月29日；六种状态互斥，未登记不自动算旷课。排序采用字符串编码顺序，不是拼音顺序。

统计按记录次数计算。同一人不同日期或时间段计为多次；MFC顶部人数按学号去重，与记录数分开显示。异常包含旷课、迟到、早退，请假包含事假和病假。日报需选择一个月日，其他报表统计全部记录。

数据文件为 `attendance.db`，保存格式保留原有 `ATTENDANCE_V1`，已有合规数据可继续读取。保存先写临时文件，成功后替换原文件；失败撤销本次变更，损坏文件不自动覆盖。文件锁用于防止同时写入同一数据文件，不是额外菜单功能。

五类报表保存为 `report_detail.txt`、`report_daily.txt`、`report_summary.txt`、`report_abnormal.txt`、`report_leave.txt`。再次查看会更新同类报表文件，日报只保存当前选定日期。

MFC使用可执行文件所在目录的数据；`run.bat`也使用项目目录。不同文件夹的程序使用各自的数据库。使用说明见 [MFC说明](mfc/README.md)。
