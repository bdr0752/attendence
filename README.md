# 大学生考勤系统

根据题目实现的 C11 控制台程序，使用结构体数组、函数和文件操作完成学生管理、考勤管理及统计。Windows 控制台支持彩色标题和状态；文件与源码统一使用 UTF-8。

现已增加 MFC 图形界面版本，双击根目录 `run_mfc.bat` 启动。MFC编译使用 `build_mfc.ps1`，原 `build.ps1` 仍编译控制台版本。具体操作、环境与验证范围见 [MFC说明](mfc/README.md)。

## 启动和快速试用

双击 `run.bat`。该脚本会将工作目录切换到项目目录，运行 `attendance.exe`。首次运行没有数据是正常情况。

1. 选择 `11`，输入 `1`，向空库导入虚构演示数据。
2. 选择 `8`，输入 `0`，查看全部考勤。
3. 选择 `10`，选择报表类型，再选择范围。日报还需要输入月日。
4. 导出选择 `1` 生成文本、`2` 生成 CSV、`3` 同时生成两种。
5. 选择 `0` 退出，再次启动可读入已保存数据。

演示数据包含 3 名学生、10 月 1 日至 10 日、时间段编号 1～10，共 30 条记录，覆盖六种状态。它只允许导入空库，不会覆盖已有学生或考勤。

## 菜单

| 编号 | 功能 |
| --- | --- |
| 1～4 | 新增学生、修改学生、删除学生、学生列表 |
| 5～7 | 新增考勤、修改考勤、删除考勤 |
| 8 | 全部考勤，或按学号、姓名、日期、班级精确查询 |
| 9 | 按学号、姓名、日期升序排列考勤 |
| 10 | 明细、日报、汇总、异常、请假五类报表，支持范围筛选和导出 |
| 11 | 向空库导入演示数据 |
| 12 | 独立查询学生，包括未登记考勤的学生 |
| 13 | 查看校验规则、统计口径和操作说明 |
| 14 | 校验并恢复最近一次变更前的备份，操作前确认 |
| 0 | 退出 |

学生学号唯一。修改学生时可更改学号、姓名和班级，直接回车保留该字段原值；新学号不能重复，关联考勤会同步改为新学号。全部字段未变时不重新保存，也不覆盖备份。

考勤以“学号＋月日＋时间段编号”唯一，必须关联已有学生。修改考勤可更改日期、时间段和状态，目标键冲突时拒绝修改。删除学生会同时删除关联考勤，操作前显示影响条数并确认。

主菜单显示记录覆盖的不同日期数量和不同时间段编号数量。时间段仅是编号，未给它指定实际上下课时间。

## 可配置的校验规则

学校的实际学号、姓名规则尚未提供。`rules.ini` 是本版本的默认规则，可编辑后重新启动；请不要把默认值当作学校要求。

| 配置项 | 默认值 | 含义与允许范围 |
| --- | --- | --- |
| id_min | 1 | 学号最少字符数，1～31 |
| id_max | 31 | 学号最多字符数，1～31，不能小于 id_min |
| id_digits_only | 0 | 1 为仅数字；0 允许 ASCII 字母、数字、下划线、连字符 |
| name_min | 1 | 姓名最少字符数，1～31 |
| name_max | 31 | 姓名最多字符数，1～31，不能小于 name_min |
| name_strict | 1 | 1 启用姓名格式限制；0 仅检查字符数、UTF-8和基本存储格式 |
| abnormal_mask | 50 | 异常状态位掩码，1～63，默认包含旷课、迟到、早退 |

配置每行使用 `键=整数`，空行和以 `#` 开头的注释被忽略；未知键、重复键、越界值、矛盾范围均会导致启动停止，数据文件保留。

严格姓名模式允许汉字范围及 ASCII 英文字母，允许内部单个空格、连字符 `-` 和间隔号 `·`，不允许数字、连续连接符或首尾连接符。例如 `张三`、`阿·布`、`Anne-Marie`。含重音字母或其他文字的姓名可将 `name_strict` 设置为 `0`。格式检查不验证姓名是否真实。

异常状态的位值依次为：出勤 1、旷课 2、事假 4、病假 8、迟到 16、早退 32。将要纳入异常表的位值相加，例如默认 `50=2+16+32`。菜单13与异常文本报表会显示实际采用的状态。

学号保留前导零。姓名和班级字段各最多 95 个 UTF-8 字节；不能含非法 UTF-8、控制字符、竖线 `|` 或首尾 ASCII 空白。系统最多支持 500 名学生、20000 条考勤，时间段编号为 1～99。这些容量均为实现限制。

配置规则用于新增或修改的学生字段。原有合法存储格式的数据可继续加载，编辑时回车保留的字段也不会被新规则强制改变；因此收紧规则后，需要自行核查既有数据是否符合学校要求。

## 报表规则

- 六种状态互斥：出勤、旷课、事假、病假、迟到、早退，一条记录只选一种。
- 统计单位是考勤记录次数，同一人一天多个时间段计为多次。
- 明细、汇总、异常、请假表可按班级、日期范围或二者组合筛选；日期范围包含首尾日期。
- 日报可筛选班级，统计选定日期所有时间段。
- 汇总和请假表会列出范围内班级的所有学生，包括该日期范围没有记录的学生，计数为零。
- 异常表按 `abnormal_mask` 分类，请假合计固定为事假加病假。
- 未登记不自动算旷课。本版没有应到名单或课程安排，不计算出勤率。
- 文本报表包含筛选范围、合计和统计口径；CSV 导出相同筛选范围的记录或学生汇总，合计可在表格软件中求和。

文本文件名为 `report_detail.txt`、`report_daily.txt`、`report_summary.txt`、`report_abnormal.txt`、`report_leave.txt`，CSV 使用同名 `.csv` 后缀。重新导出会覆盖同类同格式的旧报表；需要保留多个日期的报表时，请另存或重命名。

CSV 使用带 BOM 的 UTF-8，字段内引号和逗号会正确转义。文本字段若以公式起始字符开头，会加单引号作为文本处理。表格软件可能自动转换学号，导入 CSV 时应将学号列设置为文本，以保留前导零。

## 保存、备份与恢复

每次数据变更后立即保存。程序先写 `attendance.db.tmp`，刷新、同步并关闭成功后，备份当前文件为 `attendance.db.bak`，再替换 `attendance.db`。任一步失败都会撤销本次内存变更；导出报表也先写临时文件，成功后替换原报表。

备份只保留最近一次成功变更前的数据，不是历史版本库。首次保存前没有数据文件，因此没有备份。菜单14先校验备份再确认恢复；恢复成功后，恢复前的当前数据成为新的备份。恢复失败会保留原内存及数据文件。

加载时检查字段、日期、UTF-8、容量、重复键及学生关联；损坏文件会导致启动停止。若当前文件已损坏、无法进入菜单，可在程序全部退出后，先复制损坏文件留存，再用已确认有效的 `attendance.db.bak` 副本替换 `attendance.db`。

Windows 下通过独占文件句柄阻止多个程序同时操作同一数据库；`attendance.db.lock` 保留在目录中，正常退出或程序终止后操作系统释放锁，不需要删除该文件。

`run.bat` 使用本项目目录存放数据。若从其他目录直接启动 `attendance.exe`，配置、数据、备份与报表均使用那个工作目录。文件替换和备份降低写入失败风险，不承诺突然断电时绝对不丢数据，重要记录仍需另外备份。

## 题目对照与尚未明确的内容

新增、查找、修改、删除、部分或全部显示、排序、五种报表、文件读写、循环菜单及六种考勤符号均已实现。使用结构体数组，函数带功能说明，关键处理有注释；提供彩色控制台界面及可选的 MFC 图形界面。

题目只要求月日，因此没有年份并允许 2 月 29 日；跨年度使用应分开目录。学号按字符串排序，中文姓名按 UTF-8 编码顺序排序，未实现拼音排序。题目中的“考勤时间段不少于十条”表述仍待确认；演示数据现已同时覆盖十个日期、十个不同时间段编号，但没有凭空指定真实课程时间。

实际学校的字段规则、老师认可的报表统计口径和界面评价标准，仍需确认后按配置或代码调整。

## 编译与验证

修改源码后，在本目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

编译依赖 GCC，当前开发机使用 MinGW GCC 15.2.0。程序为 C11，Windows 版使用控制台颜色、文件同步与独占锁相关系统接口；未验证早期 TC 或 VC++6.0 环境。控制台符号显示取决于终端字体。

`test_system.py` 在独立临时目录中启动实际程序，验证操作、持久化、筛选与导出，测试不会改动实际使用的数据。使用 Python 3 执行：

```powershell
python .\test_system.py
```
